# Career Data Feasibility Matrix

Status: active source-control checklist.

This matrix preserves the full "Bryce Baseball Savant" data ambition and tracks which categories are actually source-backed. It should be updated whenever a new importer, source probe, or manual extraction pass changes feasibility.

## Project Impetus

The data program exists because BryceCast only matters if the analytics are source-backed. The active goal is to collect every relevant public or authorized racing fact that can support live race context, career benchmarks, track/weather tendencies, field and teammate comparisons, racecraft, reliability, and future race-day analysis. Social media and popularity scraping are not a primary objective; include a post or article only when it is the controlling source for a race fact, quote, media asset, sponsor/team context, or public career milestone.

## Rules

- Treat this as the anti-slip checklist. If a desired category is not in this matrix, add it before starting the next collection pass.
- Prefer official APIs/JSON/CSV first, then official HTML/PDF, then reputable aggregators as cross-checks.
- Keep source tier, grain, and confidence separate. A field can be feasible at season grain but unavailable at lap grain.
- Weather APIs are ambient context unless they expose an actual track/surface field. Track temperature and track condition need their own source labels.
- Do not render a category as production analytics until it has source provenance and passes validation.
- Live features require live or locally archived live sources. Static maps, seed data, or stale Race Control rows cannot satisfy live analytics unless the UI labels them as reference, seed, stale, or cold.
- Derived metrics need an input manifest: source rows, join keys, calculation version, exclusions, and confidence. If that manifest does not exist, the metric stays out of production UI.

## Data Quality Audit Requirements

Before a category can power the UI, it needs all of the following:

- Source authority recorded: official source, team/driver-provided source with permission, reputable cross-check, or manual extraction.
- Grain verified: season, event, session, result, lap, annotation, weather observation, media asset, or derived metric.
- Join keys verified: driver id, session id, event id, track id, car/team id where relevant, and source-specific external ids preserved.
- Time/location verified for weather or live context: timezone-aware session window, track coordinates, source coordinates or official session condition provenance, and distance/approximation notes when applicable.
- Rerun behavior checked: importer reruns must not duplicate rows, re-add stale broad gaps, erase cross-series Bryce identifiers, or overwrite unrelated source-family fields.
- Production status assigned: source-backed now, partial, candidate, manual-only, blocked, or out-of-scope.
