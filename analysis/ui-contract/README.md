# UI Contract Artifacts

This folder contains the machine-readable product analytics contract for the BryceCast frontend lane.

- `ui-metric-manifest.json` is the canonical manifest for v1/v1.5 screen, card, and chart contracts.
- `../../docs/UI_ANALYTICS_PRODUCT_CONTRACT.md` is the reader-facing version of the same contract.

The manifest deliberately points at existing generated reports, analysis CSVs, and API endpoints. It does not promote unsupported metrics into the UI contract.
